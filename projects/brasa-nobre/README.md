# Brasa Nobre — site demonstrativo

Projeto conceitual de restaurante / hamburgueria gourmet criado para portfólio.

## Destaques
- hero com hambúrguer colorido e texto à esquerda
- pedido online com formulário
- envio automático para o WhatsApp com mensagem pronta
- layout responsivo

## Observação
As imagens usadas neste projeto são ilustrativas e servem apenas para demonstração.
