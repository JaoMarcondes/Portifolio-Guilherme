# Golden Blend Barbers — V2

Redesign do conceito de barbearia do portfólio.

## O que mudou

- hero em tela cheia com fotografia de fundo;
- visual mais próximo de um negócio real e menos de uma demo de UI;
- removidos cards arredondados, swatch de cor e textos explicando o próprio design;
- tipografia mais direta e linguagem mais humana;
- serviços simplificados;
- menu mobile;
- formulário de agendamento que abre uma mensagem pronta no WhatsApp;
- animações discretas e suporte a `prefers-reduced-motion`.

## Imagens

As duas fotografias usadas no layout são carregadas do Unsplash e estão indicadas no rodapé como imagens de referência. Para produção, o ideal é substituir pelas fotos reais da barbearia e hospedá-las localmente em `assets/`.
