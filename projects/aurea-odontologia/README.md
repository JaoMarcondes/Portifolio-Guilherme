# Auréa Odontologia — projeto demonstrativo

Site conceitual de odontologia premium criado para portfólio.

## Experiência principal
- hero sticky controlado por scroll
- iluminação acendendo em sequência
- zoom progressivo
- parallax com mouse
- spotlight interativo
- reflexo animado
- texto sincronizado com a iluminação
- cards com spotlight
- CTAs em glassmorphism

## Observação
As imagens utilizadas são geradas por IA e o projeto não representa uma clínica real.
