# Lumière — site demo de salão de beleza

Projeto estático em HTML, CSS e JavaScript.

## Arquivos principais
- `index.html`
- `styles.css`
- `script.js`
- `assets/salon-bg.mp4` — vídeo do hero
- `assets/*.webp` — imagens otimizadas usadas nas seções

Abra `index.html` no navegador ou publique a pasta em Vercel/Hostinger.

Observação: endereço, e-mail e nome do salão são demonstrativos e podem ser trocados no `index.html`.


## Aviso
Projeto conceitual de demonstração. As imagens utilizadas foram geradas por inteligência artificial.
